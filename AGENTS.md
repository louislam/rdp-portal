# AGENTS.md

Technical notes for working on RDP Portal. User-facing docs live in [README.md](README.md).

## Scope

Windows-only desktop app. It launches `mstsc.exe` and uses DPAPI, so there is no
cross-platform build to maintain: `build/` holds Windows assets only.

## Stack

| Layer | Choice |
| --- | --- |
| App shell | Wails v3.1 (`github.com/wailsapp/wails/v3`) |
| Backend | Go 1.24+, no cgo |
| Frontend | Vue 3 (Options API), Bootstrap 6.0.0-alpha.1, Vite |
| Config | `config.json` next to the exe, `.rdp` files in `rdp-files/` |

## Layout

| Path | Contents |
| --- | --- |
| `main.go` | Wails app, window options, portable cwd, CDP hook for tests |
| `app.go` | `PortalService`: the only API the frontend can call |
| `internal/core` | config, profiles, `.rdp` generation, DES + DPAPI |
| `frontend/src/App.vue` | UI (Options API, one component) |
| `frontend/src/style.css` | WinForms-like shell around Bootstrap controls |
| `frontend/bindings/` | generated by `wails3 generate bindings` - do not edit |
| `build/` | Windows icon, manifest, NSIS/MSIX templates, `config.yml` |
| `e2e/run.mjs` | end-to-end test driver (CDP, no extra dependencies) |

## Behaviour worth knowing

- **Portable**: `main.go` chdirs to the exe folder, so `config.json` and
  `rdp-files/` always sit next to the exe.
- **Placeholder row**: a config with no profiles gets one unsaved row
  (`IsPlaceholder`). Clicking New reuses it instead of stacking rows, and
  `Config.Save` never writes placeholders to disk.
- **Password layering**: `config.json` stores DES-CBC/PKCS7 (`StringUtil` key/iv
  from 1.x) so the folder is portable; the `.rdp` gets a DPAPI
  `password 51:b:` blob, which only works for the same user on the same machine,
  so it is regenerated locally on every save.
- **Port split**: the UI edits hostname and port separately; `JoinAddress` omits
  port 3389 so existing `.rdp` output is unchanged.
- **`.rdp` rewriting** keeps everything mstsc wrote (resolution, audio, ...),
  replaces the connection fields and recalculates `winposstr` for the current
  screen.
- **More RDP Options...** is disabled while editing, because mstsc needs a saved
  `.rdp` file (`buttonOptions.Enabled = !editMode` in the original).
- **Window sizing**: Wails sizes windows in logical pixels; the layout is
  `height: 100%` with no document scrollbars.

## Gotchas

- Bootstrap 6.0.0-alpha.1 sets `scrollbar-gutter: stable` on `:root`, which
  reserves a grey strip on the right edge. `style.css` overrides it with
  `scrollbar-gutter: auto`.
- Do not add `wails3 generate icons` back into the build: it always writes a
  macOS `.icns` (`build/darwin/icon.icns`) and fails when that folder is absent.
  `build/windows/icon.ico` is committed; regenerate it by hand if the icon
  changes.
- `APP_NAME` in `Taskfile.yml` must stay `RDP-Portal` - it names the exe and is
  referenced by the NSIS/MSIX templates.
- `frontend/node_modules` is Dropbox-ignored (`di ignore node_modules`); run it
  after any `npm install`.

## Build

```bash
wails3 build                    # -> bin/RDP-Portal.exe, version from build/config.yml
wails3 package                  # NSIS installer, needs makensis
```

Version lives in `build/config.yml` (`info.version`) and `Version` in `app.go`;
they must match.

## Tests

```bash
go test ./... -count=1 -cover            # core + service layer
cd frontend && npm test                  # Vue component tests (bindings mocked)
node e2e/run.mjs                         # real exe, real WebView2 (build first)
```

- `e2e/run.mjs` copies `bin/RDP-Portal.exe` to a temp folder, launches it with
  `RDP_PORTAL_CDP_PORT`, drives the window over the devtools protocol and asserts
  on both the DOM and the `config.json` / `rdp-files/*.rdp` that get written.
- Not covered: `Connect` / `ShowMoreOptions` (they exec `mstsc.exe`; only their
  error paths are tested).
- The E2E runs against the built binary, so always `wails3 build` before it.
